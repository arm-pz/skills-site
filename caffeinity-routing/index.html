Caffeinity Routing

Start here. Tell it the outcome you want and it picks one of twelve brews (workflows), lists the skills in order with what each hands the next, and names the ones you have not installed instead of improvising their work.

4 files and 415 lines, free under MIT. Built from arm-pz/caffeinity-skills at b169944.

What it is for

Picks which caffeinity skills to run, in what order, for a goal that spans more than one of them, and says what each step hands the next: build and publish a skill, get a project found, pass a release gate, grow organic search traffic, run a job search, make a decision, learn a skill, run cold outbound, launch a one-person product, set up a coding agent for a repo, or set up and keep the skills themselves healthy. Checks which of those skills are installed and names the missing ones instead of improvising their work. Use whenever someone asks which skill to use, what to run first, how the skills fit together, or describes a multi-step outcome such as "take this idea to a published skill" or "get my site ready to ship and ranking", even if they never name a skill.

Not for

  • A request one skill already owns (load that skill directly)
  • Not for doing a step's work itself: the named skill does it
