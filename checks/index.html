Four rules every tool keeps.

  • Your work stays on your machine

    Each tool is a script in the page. What you give it is read in your browser and is not sent to us. Skill Check fetches a public file from GitHub only when you give it a GitHub link.

  • Not checked is never a pass

    A script can count, match and parse. It cannot judge. Every result lists what was left unchecked, so a clean screen never claims more than it looked at.

  • The skill does the rest

    Each tool comes from an open skill that your own agent can run in full. Every result links to it, so the free check is never a dead end.

  • You can read the code

    Each page loads a short script you can open, and the skills they come from are MIT-licensed repos under arm-pz on GitHub.

Before you paste.

Are the tools really free?

Yes. All six are free, with no sign-up, no trial and no limit on how often you run them. The skills they are built from are free and MIT-licensed too. We charge only when you ask a person to do the work: a hand tune-up of a skill, a hand edit of a draft, or custom skills for a team.

Where does what I paste go?

Nowhere. Each tool is a script that runs in the page, so your text or file is read on your own machine and is not sent to us. The one network request is in Skill Check, which fetches a public file from GitHub when you give it a GitHub link.

Do I need an AI agent to use them?

No. The tools need only a browser. An agent such as Claude Code, Cursor or Codex is needed only if you want to run the full skill behind a tool.

If a tool finds nothing, is my work good?

Not necessarily. A script can count, match and parse, but it cannot judge. Every result lists what was left unchecked, and an unchecked item is never shown as a pass.

What do the paid options cover?

A person does the fix. A skill tune-up is $29 for one skill or $99 for up to five that work together, and a hand edit of a draft is $29 for up to 1,500 words. Each comes back within two or three working days, and the $29 jobs are refunded in full if we find nothing worth changing.
