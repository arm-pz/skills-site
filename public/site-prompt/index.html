Site Prompt

Turns a website topic into one self-contained, paste-and-build prompt: it builds and verifies the site in a scratch folder first, then embeds every file verbatim with a pinned stack and the checks that actually ran.

8 files and 870 lines, free under MIT. Built from arm-pz/site-prompt at 3527941.

What it is for

Writes one self-contained, paste-and-build prompt for a website from a topic. Narrows the topic to a concrete subject, derives the concept from that subject's world, builds and verifies the site in a scratch folder, then embeds every file verbatim with a pinned stack, final copy, code-native visuals and the checks that were actually run.

Reach for it when

  • The user asks for a website prompt, one-shot build prompt, mega-prompt or SELENE-style prompt for a new site, landing page or one-pager.

Not for

  • Building, hosting or reviewing the site itself, not for redesigning an existing page, and not for authoring skills
