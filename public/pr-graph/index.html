How one pull request reached merge

On 24 November 2026, the graph reviewed the change that introduced its own merge gate in Skills Site. Here’s what happened on pull request #77.

  1. Review. The reviewer found three ways the gate could accept a PR too soon. It could ignore a failed review verdict, miss a failing commit status, or reuse a review after the base branch changed.
  2. Fix. The fixer addressed each finding in a separate commit on the PR branch. Read the fix report.
  3. Re-review. A fresh reviewer confirmed all three fixes. Three medium findings remained, and the CI check passed.
  4. Merge decision. The gate held the PR because it changed the rules for merging. It later landed on main through the human-merge path.
