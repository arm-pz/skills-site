What would stop this page ranking?

Paste a page's source and SEO Check reads it the way a crawler does. Each finding quotes the tag it came from. A check it could not run is listed as not checked and is never counted as a pass.

Check a page.

What it checks.

The single-page checks from seo-crawl, the open skill that crawls a whole site. Thresholds such as 60 characters for a title are rules of thumb for what search results display, not limits set by any search engine.

  • Indexability. A noindex in the meta robots tag, which removes the page from search.
  • Title. Present, single, and a length that will not be cut off.
  • Meta description. Present and a useful length.
  • Canonical tag. Present, single, absolute, and pointing at this page.
  • H1. Exactly one.
  • Language and viewport. Both set, so the page is read correctly on a phone.
  • Sharing tags. Open Graph title, description and image.
  • Images. Each has an alt attribute.
  • Structured data. Every JSON-LD block parses.
  • Links. Links with no real address, which a crawler cannot follow.

Before you paste.

Why paste the source instead of typing a URL?

A web page is not allowed to read another site's pages, and this tool has no server to fetch them for you. The upside is that it works on pages nobody else can reach: a local build, a staging site, a page behind a login.

Where does the source go?

Nowhere. It is parsed in your browser as an inert document, so its scripts do not run and nothing in it is loaded or sent.

My site is built with React or another JavaScript framework.

Then the raw source may be an empty shell, and the tool will say so. Paste the rendered HTML instead: open the browser's developer tools, right-click the <html> element and copy its outer HTML.

Will fixing these make my page rank?

No tool can promise that. These are the technical faults that stop a good page being indexed or shown properly. Whether it ranks depends on the content, the competition and links, none of which is in the source.

What does it leave out?

Anything the server sends rather than the page: status codes, redirects, headers, robots.txt, the sitemap. It also has no rankings, clicks or backlinks, and it does not measure speed. The result lists these as not checked.
