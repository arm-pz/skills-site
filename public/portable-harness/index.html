What it is for

Set up a repo so any coding agent (Claude Code, Codex, Cursor) behaves the same wherever it runs - writes 12 working rules at the top of CLAUDE.md or AGENTS.md, adds map sections only where the agent keeps getting things wrong, and installs guardrails it cannot talk past - a type check that fails only on new errors, live-service tests that run only on request, and tests plus type check before every deploy from main.

Reach for it when

  • Someone wants agent rules for a repo, a better CLAUDE.md or AGENTS.md, says the agent keeps ignoring conventions, hiding behind old type errors or calling real services in tests, or wants their setup to move between harnesses, even if they never say harness.

Not for

  • Pruning or auditing a setup that already exists (use harness-audit)
  • Reviewing code (use consistent-code-review)
  • Writing features or fixes (use production-code)
  • Turning a skill into a Claude Code plugin (use skill-to-mod)
