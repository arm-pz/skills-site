release

Web Preflight

Checks a site you own before you ship it, without pretending a status code is a finding. A 200 on /.env that matches the app shell is catch-all routing, a blanket 403 is an unanswered question, and a check that never ran becomes INCONCLUSIVE — never a pass.

Shown working, 24 Oct 2026, on skills.caffeinity.com. Probed 19 sensitive paths; nothing exposed and every security header in place: PASS. See the run

seo

SEO Crawl

Crawls a site you own and returns deterministic, evidence-backed technical SEO findings, with blocked or unrun checks reported INCONCLUSIVE rather than a pass.

Shown working, 24 Oct 2026, on skills.caffeinity.com. Found one broken internal link across 24 pages; the re-crawl after the fix came back clean. See the run

authoring

Tune Skill

Audits and fine-tunes a skill that already exists: the description that never fires, overlap with installed siblings, stale names and counts, handoff contracts that do not hand off. Ships check_skill.py, a deterministic validator over frontmatter, folder and heading agreement, description length and reference paths that do not exist. Not for creating one from scratch; that is draft-skill.

Shown working, 24 Oct 2026, on the 42 skills in this catalogue. Caught one skill that strict installers could not load; fixed in that skill and in tune-skill. See the run

Everything, in the agent you use.

One plugin carries every skill on this site plus eleven agents, one per workflow. Or take a single skill into any agent that reads a SKILL.md.

Claude Code

Every skill, plus the eleven agents: skill-builder, release-gatekeeper, seo-lead and the rest.

Codex

The same plugin from the Codex marketplace in the repo; then install caffeinity from the Plugins directory. caffeinity-routing picks the brew.

Any agent
