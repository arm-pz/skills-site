We publish twelve workflows, each a chain of open skills that hand work from one to the next. Type your goal in your own words and the page draws the chain that fits, with the lines to install it.

Before you type.

How does it choose a route?

By matching words. It compares what you typed with each workflow's title, its summary, the skills in it and a short list of everyday words for the same job. There is no language model behind it, so it shows you which words matched and offers the next closest route.

Where does what I type go?

Nowhere. The page loads the list of workflows once and does the matching in your browser.

Do I have to run every skill in the route?

No. Steps marked optional can be skipped, and each skill works on its own. The order matters when you do run them, because each one hands its output to the next.

How do I run a workflow once the skills are installed?

Ask your agent for the outcome in plain words. The caffeinity-routing skill names the workflow and the next skill; in Claude Code, each workflow also has its own agent in the caffeinity plugin.

None of the routes fit my work.

Then it is probably a skill nobody has written yet. We build custom skills at a fixed price; see custom work.
