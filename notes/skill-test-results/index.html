What happened when we tested 59 skills and mods

15 PASS, 44 PARTIAL, 0 FAIL in the November Claude Code batch.

Skillsmith by Caffeinity · 20 November 2026 · Notes

We gave each skill or mod a task in Claude Code and kept a report of what happened. Some tasks used prepared examples. Others worked against the live site. The reports show what the agent got right, what it missed and how the run was graded. Read all 59 results.

What a partial run looks like

We asked SEO Sweep to crawl skillsmith.tech, fix what it found in the source and verify the changes locally. It found 12 titles over 60 characters and eight descriptions over 160. After its edits, the local crawl found zero long titles and two long descriptions.

The agent skipped parts of the workflow, including checking which page should rank for each search query. It left a long description on a generated workflow page untouched. The changes stayed local, and the run got PARTIAL. Read the SEO Sweep report.

How to read the verdicts

A verdict belongs to the task in the report. For example, Get Indexed passed a planning run by counting the 92 URLs in the sitemap and listing what submission would require. That task stopped at the plan. Read the Get Indexed report.

The nightly check looks for structural problems in the published skill files and broken references to other skills. The behavioral runner gives an agent a task and reviews its actions and output against a rubric. Some scenarios also check files or compare the result with a known answer.
