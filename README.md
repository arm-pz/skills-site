# wordsmith — landing page

A single-file install page for the [wordsmith](https://github.com/arm-pz/wordsmith) agent skill.

No build step, no dependencies: `index.html` contains all markup, styles, and scripts.

## Run locally

Open `index.html` in a browser, or:

```sh
npx http-server -p 8080
```

## Deploy

Any static host works as-is (GitHub Pages, Netlify, Cloudflare Pages).
