Production Code

Delivers code as a finished artifact rather than a snippet: complete scripts, bug fixes with the root cause, reviews, API integrations and SQL, each with the run instructions and the edge cases handled.

4 files and 326 lines, free under MIT. Built from arm-pz/production-code at b02ff78.

What it is for

Production-ready code delivered as a complete artifact: scripts, bug fixes with the root cause, API integrations, SQL of any complexity, automation jobs, scrapers, data analysis in pandas or R, technical documentation and architecture write-ups, each with setup steps, error handling and a plain-English explanation of every section. Use whenever someone describes something they want code to do, pastes an error or a snippet to fix, asks for a query, a scraper, an automation or a system design, even if they never say write code or name a language.

Not for

  • Auditing a live web app before launch (use pre-ship-performance-audit, pre-ship-security-red-team)
  • For the business decision behind the build (use strategy-memo)
  • For reviewing code or a diff without changing it (use consistent-code-review, which this skill calls for its review mode)

More in Build & Ship

  • Site PromptTurns a website topic into one self-contained, paste-and-build prompt: it builds and verifies the site in a scratch folder first, then embeds every file verbatim with a pinned stack and the checks that actually ran.
  • Web PreflightChecks a site you own before you ship it, without pretending a status code is a finding. A 200 on /.env that matches the app shell is catch-all routing, a blanket 403 is an unanswered question, and a check that never ran becomes INCONCLUSIVE — never a pass.
  • Pre Ship Security Red TeamRed-teams a web app you own before launch, in an isolated local environment. Three parallel read-only subagents run fourteen authorization and abuse checks across three groups (identity and authorization; UI and API bypass; browser, network, cache and AI), each with captured evidence, then the fix is rerun against the same check. A check that cannot fail is falsified first, and findings stay on the record even when the pass clears.
