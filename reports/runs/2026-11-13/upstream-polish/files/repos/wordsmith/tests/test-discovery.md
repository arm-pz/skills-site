# Discovery Tests

The skill should activate for requests containing these intents:

- Rewrite this paragraph.
- Proofread this email.
- Make this clearer.
- Improve the grammar.
- Make this more concise.
- Change the tone to warm and professional.
- Write a headline.
- Prepare this article for publication.
- Create three alternatives for this website copy.
- Draft a welcome message for new users.
- Tighten this announcement by 30%.
- Simplify this technical explanation.
- Audit this proposal for unsupported claims.
- Polish this draft before sending.

The skill should NOT activate for:

- Code generation or debugging requests
- Data analysis or visualization tasks
- Design or layout requests (use impeccable/frontend-design instead)
- Legal/medical/financial advice requests
- General conversation unrelated to writing or editing

The skill should not claim to verify facts unless the user explicitly requests fact-checking and an appropriate research tool is available.
