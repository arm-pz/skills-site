```python
import re

_AREA = r"[A-PR-UWYZ]"            # first letter: not Q, V, X
_AREA2 = r"[A-PR-UWYZ][A-HK-Y]"   # first letter as above; second: not I, J, Z
_OUTWARD = (
    r"(?:"
    rf"{_AREA2}[0-9]{{1,2}}"                 # AA9, AA99   (e.g. CR2, DN55)
    rf"|{_AREA}[0-9]{{1,2}}"                 # A9, A99     (e.g. M1, B33)
    rf"|{_AREA}[0-9][A-HJKPSTUW]"            # A9A         (e.g. W1A)
    rf"|{_AREA2}[0-9][ABEHMNPRVWXY]"         # AA9A        (e.g. EC1A, SW1A)
    r")"
)
_INWARD = r"[0-9][ABD-HJLNP-UW-Z]{2}"        # unit letters: not C I K M O V
_POSTCODE = re.compile(
    rf"(?:GIR ?0AA|{_OUTWARD} ?{_INWARD})", re.ASCII | re.IGNORECASE
)


def is_uk_postcode(s):
    """Return True if s is a well-formed UK postcode (case-insensitive).

    Leading/trailing spaces are ignored; the space before the inward code
    is optional (one space at most). Checks format only, not whether the
    postcode actually exists.
    """
    if not isinstance(s, str):
        return False
    return _POSTCODE.fullmatch(s.strip(" ")) is not None
```

## What was wrong before, and what changed

| Complaint | Cause | Fix |
|---|---|---|
| Rejects `M1 1AE` | Required exactly 2 letters + 2 digits | Outward code now allows all four real shapes: A9, A99, AA9, AA99, A9A, AA9A |
| Rejects `W1A 0AX` | No letter-suffix form | A9A and AA9A patterns |
| Rejects lowercase | No case handling | `re.IGNORECASE` |
| Accepts `SW1A 1AAXYZ` | `re.match` only anchors the start | `fullmatch` |

Also fixed: `$` would accept a trailing newline (`fullmatch` doesn't); `re.ASCII` stops non-ASCII digits and letters from matching; non-strings return `False` instead of raising; the special code `GIR 0AA` is accepted.

## Rules enforced
- First letter never Q, V or X. Second letter never I, J or Z.
- Third character of A9A must be one of A B C D E F G H J K P S T U W.
- Fourth character of AA9A must be one of A B E H M N P R V W X Y.
- Inward code is a digit plus two letters from A B D E F G H J L N P Q R S T U W X Y Z (no C I K M O V).

## Assumptions
- A missing space (`SW1A1AA`) is accepted, because users commonly type it that way. If you want the space required, change ` ?` before `{_INWARD}` to a plain space.
- Surrounding spaces are trimmed. Tabs, newlines and double inner spaces are rejected.
- This is a format check. It does not confirm the postcode is assigned. Crown dependency and overseas-territory codes (e.g. `JE`, `GY`, `IM`, `BFPO`, `ASCN 1ZZ`) are not covered, except that Jersey, Guernsey and Isle of Man codes mostly match the general format anyway.

## Expected results
Accepted: `M1 1AE`, `W1A 0AX`, `sw1a 1aa`, `SW1A1AA`, `EC1A 1BB`, `GIR 0AA`, `B33 8TH`, `CR2 6XH`, `DN55 1PT`, ` M1 1AE `.

Rejected: `SW1A 1AAXYZ`, empty string, `Q1 1AA`, `ZZ1 1AA`, `SW1A 1AA\n`, `SW1A  1AA`, `A1 1CA`, `M1\t1AE`, `SW1A 1A`, `None`, and Arabic-Indic digits such as `٣1 1AA`.
