Try the skill before you install it.

Each tool is one of our open skills, cut down to the part a browser can run. Paste your work, read what it finds, then fix it yourself or give the full skill to your agent. No sign-up, and what you paste stays in your browser.

How they work.

  • They run in your browser. Each tool is a script in the page. The text or file you give it is read on your own machine and is not sent to us. Skill Check fetches a public file from GitHub only when you give it a GitHub link.
  • They say what they did not check. A script can count, match and parse. It cannot judge. Every result lists what was left unchecked, and an unchecked item is never shown as a pass.
  • The skill does the rest. Each tool comes from an open skill that your own agent can run in full: crawl the whole site, rewrite the resume, edit the draft. Every result links to it.
  • The code is open. Each page loads a short script you can read, and the skills they come from are MIT-licensed repos under arm-pz on GitHub.
