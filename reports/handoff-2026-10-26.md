## Where things live

| What | Where |
| --- | --- |
| Single source of what is published | `site/skills.json` (skills, `quality`, `tested`, `featured`, `pairsWith`, workflows with `slug` and `summary`) |
| Hub pages (hand-written shells, generated regions) | `index.html`, `skills/`, `mods/`, `workflows/index.html`, filled by `tools/agent-skills/gen_home.py` |
| Workflow pages | `workflows/<slug>/`, fully generated from `tools/agent-skills/templates/workflow-page.html` |
| Skill pages | generated: `templates/skill-page.html` via `gen_page.py`; bespoke: hand-written, with generated quality regions |
| Site structure, naming, quality record rules | `PROJECT.md` (sections "Domains", "Site structure", "Quality record") |
| Canonical address | `skilllib.SITE`; reserved section names in `skilllib.RESERVED` |

## How to verify after any change

```
python -m unittest discover -s tools/agent-skills/tests
python tools/agent-skills/gen_home.py --check
python tools/agent-skills/gen_page.py --check
```

The full build (`build.py`, `gen_sitemap.py`, `make_dist.sh`, `check_dist.py`, `verify.mjs local`) needs
GitHub access to every skill repo; CI runs it on every PR.
