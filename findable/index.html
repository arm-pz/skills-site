the kit

Ten sections, all drafts until you say apply.

One audit produces one file: a discovery-kit.md that records what is true today, says what should change, and hands you the commands. It writes for people and search engines; the SKILL.md that triggers the agent is a separate job.

Baseline 1

Where the project appears today, and where comparable projects do.

  • search by name
  • search by task
  • same-name projects read, not assumed
  • repo metadata: About, topics, homepage, release

Target queries 5-10

What a stranger types. At least two per capability, none needing your name.

  • shown to you before anything is written
  • every later draft is written from them

Name decision 1

Only when something else already holds the name.

  • keep and qualify everywhere
  • or rename while stars are zero
  • the user decides, not the tool

Listing copy 6

The surfaces GitHub and directories actually read.

  • About within 350 chars
  • topics within 20
  • README opening
  • release notes
  • social preview brief
  • license reminder

Distribution 1

Directories worth checking, with each one's submission rules read first.

  • entry text ready to paste
  • UNVERIFIED marked where rules were not checked
  • community posts only after a real result

Re-check, dated 2

The same queries, re-run against the recorded baseline two to three weeks later. Indexing lags, so a check the day after publishing proves nothing.

  • baseline table kept
  • success defined before it is measured
  • numbers move only if they move

ground rules

What it refuses to do.

Real numbers or none

It never claims stars, installs, rankings, benchmarks or compatibility the repo does not support. Every figure on this page was fetched from GitHub in the run it describes, and the date of that fetch is stated beside it.

Nothing public without a go-ahead

The kit ends in commands you run: gh repo edit, gh release create, submission steps. The tool drafts them and stops. No description, topic, release or page changes behind your back.

No gaming, ever

No star trading or buying, no fake reviews, no topic stuffing, no undisclosed promotion, no asking for stars in communities. It also leaves example slots empty and labelled rather than writing sample output a project never produced.

Know where you rank, and what is in the way.

Free, open, and it only ever drafts. You run the commands.
