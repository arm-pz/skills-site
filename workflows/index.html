Workflows that finish a job.

Each workflow is an ordered chain of skills: every step receives what the step before it produced, and stops at its own gate. We call them brews, so each also carries a coffee name. Install caffeinity-routing and describe the outcome; it picks the route and tells you which steps you have not installed yet.

Brew 1 · Pour-over

Build a skill and make it installable

Go from an idea or a pile of prompts to a tested skill anyone can install: draft it, tune its trigger, then package and release it.

  1. draft-skill or prompts-to-skill
  2. tune-skill
  3. prompts-to-skill-release
  4. skill-to-mod optional

skill-launch runs the first steps as one chain; tune-skill-mod and skill-release-mod hold pushes and releases until steps two and three have run.

Open the workflow

Brew 2 · Bloom

Get a repo, skill or plugin found

Make a repo, skill or plugin show up for what it does: fix how it is described and listed, publish it, then check every listing matches what is live.

  1. findable
  2. publish-pipeline
  3. upstream-check
  4. get-indexed optional

findable-polish and upstream-polish add the rewrite; get-indexed applies when publishing put new or changed pages live.

Open the workflow

Brew 3 · Espresso

Decide whether a site is safe to launch

Get one honest answer to "can we ship?": check for exposed files, red-team the app, audit its speed, then let a release gate weigh the three verdicts.

  1. web-preflight
  2. pre-ship-security-red-team
  3. pre-ship-performance-audit
  4. release-gate-chair or release-gate-ledger or release-gate-validator

ship-sentinel holds git push and deploys until the gate has run.

Open the workflow

Brew 4 · Cold brew

Grow organic search traffic

Grow organic traffic on a site you own: crawl it for technical problems, give each query one page that wins it, then tighten the copy.

  1. seo-crawl
  2. keyword-guard
  3. wordsmith
  4. pre-ship-performance-audit optional
  5. platform-content optional
  6. get-indexed optional

seo-polish and keyword-resolver package parts of this route; seo-sweep runs it end to end, fixes the findings in the site's code and proves each fix with a re-crawl.

Open the workflow

  1. recruiter-lens

  4. career-track optional

Brew 9 · Moka pot

Launch a one-person product

Take a one-person product from plan to launch: pick the offer, build the site and code, write the policy pages, pass the release gate, then announce it.

  1. solo-income-blueprint
  2. site-prompt
  3. production-code
  4. paper-trail
  5. release-gate-chair
  6. platform-content

Step five is the whole of Brew 3 · Espresso; paper-trail gives the gate the policy pages to check.

Brew 10 · Descale

Maintain the skill family

Keep a family of skills healthy after release: tune what drifted, re-release what changed, and confirm every listing still matches.

  1. tune-skill
  2. prompts-to-skill-release optional
  3. upstream-check

The nightly health job opens the issue this starts from; a weekly scheduled session runs it and opens PRs. For one published skill at a time, tune-and-ship takes it from a tune and a fact check through to a release and a confirmed live page.

Open the workflow

Brew 11 · Estate roast

Stand up or audit a skill estate

Inventory and repair a whole collection of skills in one gated run, from repos and listings to the workflows that connect them.

  1. skill-estate

One run over the whole collection in eight gated phases; Brew 10 · Descale keeps it healthy afterwards.

Open the workflow

Brew 12 · Dial-in

Set up a coding agent for a repo

Get a coding agent that follows the repo's rules and stays inside its usage: write or prune the rules and guardrails, tier the models by role, then pick the effort each large task deserves.

  1. portable-harness or harness-audit
  2. setup-claude-advisor optional
  3. diagnose-usage optional
  4. choose-effort optional

Step one is one or the other: portable-harness writes a setup, harness-audit prunes one that has grown. The usage steps are for Claude Code.
