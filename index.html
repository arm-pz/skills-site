Nine routes through the catalogue

Skills that hand off to each other.

Each workflow is an ordered chain: every step receives what the step before it produced, and stops at its own gate. Install caffeinity-routing and describe the outcome; it picks the route and tells you which steps you have not installed yet.

W1

Build a skill and make it installable

  1. draft-skill or prompts-to-skill
  2. tune-skill
  3. prompts-to-skill-release
  4. skill-to-mod optional

W2

Get a repo, skill or plugin found

  1. findable
  2. publish-pipeline
  3. upstream-check
