Skillsseo-crawl

SEO Crawl

Crawls a site you own and returns deterministic, evidence-backed technical SEO findings, with blocked or unrun checks reported INCONCLUSIVE rather than a pass.

14 files and 1,886 lines, free under MIT. Built from arm-pz/seo-crawl at 9c78758.

What it is for

Runs a bounded, read-only crawl and returns deterministic findings JSON with stable IDs and explicit INCONCLUSIVE checks, so an SEO audit or content change starts from measured evidence instead of guesses.

Reach for it when

  • You need evidence about the technical SEO state of a site you own or are authorized to crawl, covering HTTP statuses and redirects, indexability (meta and header robots), robots.txt, canonical tags, titles, meta descriptions, H1s, internal links, sitemap coverage, and static JSON-LD.

Say it like this

  • Crawl the site for SEO
  • Check sitemap coverage
  • Find broken internal links
  • Why is this page not indexed
  • Check titles and metas
  • Canonical audit
  • Pre-audit crawl

Not for

  • Search Console clicks, impressions, rankings or keyword volumes
  • Core Web Vitals, Lighthouse or bundle performance
  • Release security and exposed files
  • Content rewriting or keyword strategy
