What it is for

Runs the Skillsmith by Caffeinity SEO skills on a site you own, in order, fixes what they find in the site's code, proves each fix with a re-crawl, and turns every defect a skill shows along the way into a tested fix to that skill, chaining seo-crawl, findable, keyword-guard, wordsmith and get-indexed.

Reach for it when

  • The user asks to "fix the SEO", "run the SEO skills on my site", "why doesn't my site show up when I search its name", "my brand search shows other domains", "use the skillsmith skills on this site", or wants a site's search problems fixed and the skills improved as they run, even if they never say "audit".

Not for

  • Only submitting pages to search engines (use get-indexed)
  • A report-only audit with rewrite options (use seo-polish)
  • Resolving cannibalization alone (use keyword-resolver)
  • Repo or skill discoverability alone (use findable)
  • Writing a new skill (use draft-skill)

It audits where you rank today, works out the queries strangers type, then drafts the About text, topics, README opening, release notes, site page and directory plan — real numbers only, and nothing public changes without your go-ahead.
  • Publish PipelineTurns a pile of skill repos into a published site: a committed manifest decides what is public, discovery opens a pull request, and a green merge deploys generated pages, both discovery indexes, a sitemap and a verified build.
