An idea in, a launched skill out — three gates deep.

the pipeline

Three phases, two gates, one handover.

Each phase ends in an artifact the next one consumes: a drafted folder, a validated skill with zero FAILs, a polished set of discovery surfaces. The final report states which checks ran and which publication commands are waiting on you.

Draft phase 1

Intent confirmed before anything is written; siblings checked so the new skill has one clear owner of its request.

  • purpose + trigger sketch
  • sibling overlap screen
  • scripts vs references decided
  • description written to trigger

Validate gate 1

Tune-Skill audits and edits, and the folder must pass check_skill.py with zero FAILs to move on.

  • 16 checks, exit clean
  • overlap edits minimal
  • near-miss test cases written
  • no FAIL, no advance

Polish + launch gate 2

Findable-Polish derives the queries and polishes README, About and site copy; the launch kit hands over copy-paste commands.

  • 5-10 target queries
  • About + topics drafted
  • install line verified
  • gh commands handed over

Outside its boundary 2 siblings

An existing skill that needs work runs through tune-and-polish, not this pipeline. A prompt list rather than an idea is prompts-to-skill territory. Nothing public changes without confirmation — that rule outlives every convenience.

  • no edits to existing skills
  • no unapproved publishing

ground rules

What it refuses to do.

Confirm intent before writing

A skill written from a misread idea is a repo you have to delete later. Phase one asks what it is for and who should never trigger it, then writes.

Gates, not vibes

The validator decides when phase one is done. Descriptions are measured against the checklist, and a FAIL sends the skill back to tuning instead of forward to polish.

Public changes need a go-ahead

Repos, releases and listing edits are drafted with exact commands and run only after confirmation. The pipeline prepares the launch; you pull the trigger.

From idea to launched, with a gate between every phase.

Free, open, and every launch traces back to a validated file.
