Skillspublish-pipeline

Publish Pipeline

Turns a pile of skill repos into a published site: a committed manifest decides what is public, discovery opens a pull request, and a green merge deploys generated pages, both discovery indexes, a sitemap and a verified build.

9 files and 1,273 lines, free under MIT. Built from arm-pz/publish-pipeline at 6ead5bc.

What it is for

Sets up, audits and repairs a manifest-driven CI/CD pipeline that publishes a collection of agent skills to a Cloudflare Pages site, with a generated page per skill. It installs one GitHub Actions workflow with check and publish jobs, a review-PR or auto-sync publication gate, generated hub rows, discovery indexes, sitemap and pages, and gates on both sides of the deploy.

Reach for it when

  • Someone asks for CI/CD or automation for a skills site, wants a new skill repo to appear on the site with its own page, asks why a skill is missing or its page is stale, or needs a red publish run diagnosed and a bad deploy rolled back.

Not for

  • Releasing one skill through the marketplace, tarball or plugin channels (use publish-release-gate)
  • Checking unpushed work or listing drift (use upstream-check)
  • Deciding whether a build is safe to launch (use release-gate-chair)
  • Writing and tuning a skill (use draft-skill or tune-skill)
