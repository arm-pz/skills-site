Skillscourse-builder

Course Builder

A course for a class or cohort: measurable outcomes, modules in prerequisite order, an assessment for every outcome and a time budget that fits, checked by a script before the first session.

5 files and 302 lines, free under MIT. Built from arm-pz/caffeinity-skills at b169944.

What it is for

Designs a course for a group of learners (a class, cohort, workshop series, bootcamp or internal training): measurable outcomes, a module sequence with prerequisites, activities and assessments aligned to each outcome, a time budget that fits the hours available, and a rubric, then checks the plan with a script so no outcome goes untaught or unassessed.

Reach for it when

  • Someone is teaching others and asks for a curriculum, syllabus, course outline, module plan, cohort or workshop structure, or wants an existing course checked for gaps and overload, even if they never say "curriculum".

Not for

  • One person's own learning plan (use study-system)
  • For being taught the topic (use topic-primer)
  • For marketing the course (use sales-copy)
