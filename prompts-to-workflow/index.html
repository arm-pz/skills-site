What it is for

Turns a pasted batch of prompts that together do one multi-step job into a workflow, then decides how to split it into skills. Maps the prompts to ordered steps with inputs, outputs and gates, checks every step against the live skillsmith.tech catalog and its brews, reuses existing skills such as tune-and-polish, wordsmith or findable where they fit, drafts a thin chain skill that runs the steps, and writes a brief for each new skill only where nothing covers a step. Use whenever the user pastes prompts or a prompt log and asks to make it a workflow or a brew, split it into skills, work out which skills they already have, or stop doing these steps by hand, even if they never say "workflow".

Not for

  • Prompts that each become their own skill (use prompts-to-skill)
  • A single idea (use draft-skill or skill-launch)
  • An outcome described without prompts (use caffeinity-routing)
  • An existing skill (use tune-and-polish)
